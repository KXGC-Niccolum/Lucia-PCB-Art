# Lucia PCB Art

## 项目简介

## 工艺说明

> 此部分旨在为尚不了解PCB生产工艺而有自主修改或创作需求的读者提供指引，若无需要可直接略过。

- 覆铜层（在立创EDA中表示为“顶层”或“底层”）：为基板上的覆铜部分，图片上的黑色为成品上的覆铜部分，此时上方阻焊层若未开窗则只会在成品外观上体现为略微突起（可用于突出轮廓和营造层次），若开窗，则在成品上显示为金色；透明处不覆铜，上方阻焊层若开窗会露出基板本色。

- 丝印层：彩色丝印的放置层级。

- 阻焊层：位于覆铜层与丝印层之间，黑色处为开窗部分，透明处为覆盖阻焊涂料的部分。

- 板框层：标定板框轮廓的层级。

其余层级在此作品中无作用。

## 使用方式

### 方式1：嘉立创EDA源工程

1. 打开嘉立创EDA专业版；
2. 文件 → 导入，选择本项目内的`ProPrj_Lucia-PCB-ART_2026-10-11.epro2`；
3. 核对：板厚、丝印工艺、阻焊层颜色（白色）；
4. 直接提交打样。

### 方式2：Gerber生产文件

直接使用 `Gerber_PCB1_2026-09-06.zip` 提交 PCB 工厂生产。

> **注意**：核对文件中的彩色丝印是否**正确生效**；向工厂确认支持**双面彩色丝印+沉金/镀金**工艺。

## 打样参数（嘉立创下单页参考值）

下单时请核对以下参数：

| 参数     | 取值                            |
| -------- | ------------------------------- |
| 板材类别 | FR-4                            |
| 板子尺寸 | 6 cm × 10 cm                    |
| 板子层数 | 2 层                            |
| 板子数量 | 按需选择（常见 5 / 10 片）      |
| 拼板款数 | 1                              |
| 出货方式 | 单片                           |
| 成品板厚 | 0.8mm -1.6 mm 均可（推荐 1.6mm） |
| 外层铜厚 | 1 oz                            |
| 阻焊颜色 | 白色                            |
| 字符颜色 | 黑色                            |
| 阻焊覆盖 | 过孔盖油                        |
| 焊盘喷镀 | 沉金（金色，1 u"，收费项）      |
| 最小孔径 | 0.3 mm                          |
| 线路测试 | AOI 全测 + 飞针全测             |
| 字符工艺 | 嘉立创EDA彩色丝印                |
| 交期    | 正常 3 天                       |

> **彩色丝印**与**沉金**是本板效果的关键项，阻焊建议选择**白色**；其余为嘉立创默认选项，下单页如与本表有出入，以页面实际显示为准。
